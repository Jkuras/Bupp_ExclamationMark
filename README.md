# Bupp_ExclamationMark
Game Devices and Controllers for Bupp! the band from Seattle

Button Doodad is the first iteration of this project, and has since been deconstructed and rebuilt with slightly different circuity, and an added 4x4 keypad. The code is no longer in use.

Button Doodad V2 is the current in-progress iteration. The construction is more user-friendly to assemble, and sampler controls are more accessible via keypad and two large MC buttons. Circuit construction and testing is in progress, and code is incomplete.
